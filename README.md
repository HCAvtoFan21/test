# ЭЛОу АВТ - Тренажерный комплекс цифрового двойника

Компьютерный тренажерный комплекс для подготовки операторов оборудования ЭЛОу АВТ.

## Описание

Это веб-приложение представляет собой интерфейс тренажерного комплекса, основанного на цифровом двойнике оборудования ЭЛОу АВТ. Система предназначена для:

- Обучения операторов
- Повышения квалификации специалистов
- Тренировки аварийных процедур
- Оценки знаний и навыков

## Использование

1. Откройте файл `index.html` в веб-браузере
2. Навигируйте по разделам используя меню
3. Нажимайте кнопку "Начать обучение" для перехода к программам
4. Заполняйте форму контактов для связи
